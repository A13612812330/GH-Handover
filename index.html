怎么用

  1. 点任意截图看大图，右键可另存；每张图下方都写清了它展示的是什么数据。
  2. 挑一个仓库，点「打开仓库」；每个仓库的 README 都写了它自己怎么跑。需要依赖的先 npm install 或 pip install -r requirements.txt。
  3. 本机端口只是「跑起来之后才有」的地址，照上表命令起一遍即可，不需要原开发机在线。
  4. 涉及第三方登录的（飞书推送、公司后台），仓库内不含任何凭据，由使用者在界面内自行登录。
  5. 想让 AI 接手，把 PROMPTS.md 里对应段落整段复制给它。
